# Surf local font assets — licenses and sources

These WOFF2 files are local copies used by the Surf V1 design lock so
production and previews do not depend on Google Fonts CDN at runtime.

| File(s) | Family / style | Source | License |
|---|---|---|---|
| `Fraunces-Regular.woff2`, `Fraunces-Medium.woff2`, `Fraunces-SemiBoldItalic.woff2`, `Fraunces-BlackItalic.woff2` | Fraunces serif, regular/medium and italic hero weights | Google Fonts / fonts.gstatic.com, downloaded 2026-05-06 and converted from TTF to WOFF2 with fontTools | SIL Open Font License 1.1 |
| `JetBrainsMono-Regular.woff2`, `JetBrainsMono-Medium.woff2` | JetBrains Mono regular/medium | Google Fonts / fonts.gstatic.com, downloaded 2026-05-06 and converted from TTF to WOFF2 with fontTools | SIL Open Font License 1.1 |

The SIL Open Font License permits bundling, using, and redistributing the fonts
with the app, provided the license terms are preserved. Do not commit new font
families without updating this file and the Design System Lock.
