# How Surf uses AI

Surf uses Anthropic Claude to help turn your course material into study content:

- clean the class factsheet you upload,
- extract learning objectives from lecture slides,
- generate multiple-select practice questions, and
- explain why answers are correct or wrong.

Your Anthropic API key is saved only on this computer in local SQLite for Surf V1.
Surf uses the key only when you ask it to process class or lecture content. Do not
share the key in chat, screenshots, commits, or preview files.
