Create `app/class_/lo_extract/lo_extractor.py` (10-line wrapper, copy factsheet_cleaner shape exactly):
```python
"""Surf — Learning-Objective extractor.

Calls Claude once per lecture with the full lecture markdown and a
7-key subset of the cleaned factsheet, returning learning objectives
(title + inclusive page range) and an ignored-page list with reasons.
"""
from __future__ import annotations

import json
from pathlib import Path
from typing import Any

from app.brain.claude_client import call_claude

_SYSTEM_PROMPT_PATH = Path(__file__).with_name("lo_extractor_system_prompt.md")


def extract_los(lecture_md: str, factsheet_subset: dict[str, Any]) -> dict[str, Any]:
    """Extract learning objectives and ignored pages from a lecture.

    Args:
        lecture_md: full markdown produced by pdf_to_md_v3.py (with
            `--- PAGE N ---` markers between slides).
        factsheet_subset: a dict containing ONLY the 7 keys listed in D-1.2
            (curated by the orchestrator). Passing the full factsheet is a
            caller bug.

    Returns:
        dict with keys 'learning_objectives', 'ignored_pages', 'language'.
    """
    user_message = json.dumps(
        {"lecture_md": lecture_md, "factsheet_subset": factsheet_subset},
        ensure_ascii=False,
    )
    return call_claude(
        system_prompt=_SYSTEM_PROMPT_PATH.read_text(encoding="utf-8"),
        user_message=user_message,
        expect_json=True,
    )
```

Create `app/class_/lo_extract/lo_extractor_system_prompt.md` containing the system prompt. Required content (in this order):

1. **Role** — "You are Surf's Learning-Objective extractor for HSG lecture slides."
2. **Input contract** — the user message is a JSON object with two keys:
   - `lecture_md`: the full lecture markdown, with `--- PAGE N ---` markers between slides.
   - `factsheet_subset`: a dict with ONLY these 7 keys (list them verbatim):
     - `surf_extraction_notes`
     - `core_course_content.narrative_summary`
     - `FSLO`
     - `core_course_content.main_topics`
     - `core_course_content.important_concepts_models_methods`
     - `core_course_content.skills_students_are_expected_to_develop`
     - `assessment_and_grading.exam_relevant_content`
   - Explicitly state: "If any other factsheet keys appear, ignore them. Do not assume access to course logistics, prerequisites, or assessment components."
3. **Page-ignore taxonomy** — verbatim from D-1.1:
   - agenda
   - image-only (no real text)
   - sources/references-only
   - title page
   - blank
   - institutional / disclaimer / policy
   - off-topic vs factsheet (slide content unrelated to any factsheet topic)
   For each ignored page, return one of these exact reason strings.
4. **Output JSON schema** — Claude must emit ONLY this JSON (no markdown fence, no prose):
   ```json
   {
     "learning_objectives": [
       {"title": "<short LO title>", "page_range": [<start>, <end>]}
     ],
     "ignored_pages": [
       {"page_number": <int>, "reason": "<one of the 7 taxonomy strings>"}
     ],
     "language": "<two-letter code; 'en' | 'de' | other>"
   }
   ```
5. **Hard rules**:
   - Page numbers come from the `--- PAGE N ---` markers, NEVER from inferred slide content.
   - LO `page_range` is inclusive; `start <= end`.
   - LO page ranges MUST NOT overlap.
   - Every page that does not appear in `ignored_pages` MUST belong to exactly one LO's page_range (D-1.5 coverage rule).
   - Maximum number of LOs = `floor(total_pages / 5)` (D-1.4); aim for fewer when content allows. (Total pages = the highest N seen in `--- PAGE N ---` markers.)
   - LO titles are short noun-phrases (≤80 chars), in the lecture's language.
6. **Output discipline** — strict JSON only. No leading/trailing prose. No markdown code fence. The response is parsed directly.

Write the prompt clearly enough that Claude does not hallucinate keys. Length budget: ≤120 lines of markdown.
