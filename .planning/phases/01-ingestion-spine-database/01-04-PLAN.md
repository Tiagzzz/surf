```python
"""Surf — MCQ generator.

Calls Claude once for a batch of up to 10 slides (D-4.3) and returns
1-3 MCQs per non-ignored slide. The wrapper does NOT loop, retry, or
chunk — those concerns live in the orchestrator (Plan 05 / D-4.4-4.5).
"""
from __future__ import annotations

import json
from pathlib import Path
from typing import Any

from app.brain.claude_client import call_claude

_SYSTEM_PROMPT_PATH = Path(__file__).with_name("mcq_generator_system_prompt.md")
MAX_BATCH_SIZE = 10  # D-4.3 (locked)


def generate_mcqs(slides_batch: list[dict[str, Any]]) -> dict[str, Any]:
    """Generate MCQs for a batch of slides.

    Args:
        slides_batch: list of {"page_number": int, "raw_md": str},
            length 1..MAX_BATCH_SIZE.

    Returns:
        dict with key 'by_slide' — see system prompt for full schema.

    Raises:
        ValueError: when batch size is 0 or > MAX_BATCH_SIZE.
    """
    if not slides_batch:
        raise ValueError("slides_batch must contain at least 1 slide")
    if len(slides_batch) > MAX_BATCH_SIZE:
        raise ValueError(f"slides_batch must have at most {MAX_BATCH_SIZE} slides; got {len(slides_batch)}")
    user_message = json.dumps({"slides": slides_batch}, ensure_ascii=False)
    return call_claude(
        system_prompt=_SYSTEM_PROMPT_PATH.read_text(encoding="utf-8"),
        user_message=user_message,
        expect_json=True,
    )
```

Create `app/class_/mcq_generate/mcq_generator_system_prompt.md` containing the system prompt. Required content (in this order):

1. **Role** — "You are Surf's multiple-choice question generator for HSG lecture slides."
2. **Input contract** — the user message is a JSON object:
   ```json
   {"slides": [{"page_number": <int>, "raw_md": "<str>"}, ... up to 10 slides]}
   ```
3. **Per-slide rules** (D-2.1, D-2.2, D-2.3, D-2.8 page-ignore alignment):
   - Generate 1 MCQ per slide by default.
   - Generate 2 or 3 MCQs ONLY when the slide contains multiple distinct testable pieces of knowledge. Each additional MCQ must cover a *different* sub-topic (not a different cognitive level — no Bloom-style recall/application/edge-case rotation; just different sub-topics).
   - Detect the slide's language and write the question, options, and rationales in that language. HSG lectures often mix German and English — follow the source slide.
   - If the slide has no testable content (agenda, image-only with no real text, sources/references, title page, blank, institutional/disclaimer/policy, off-topic vs the surrounding lecture), return an empty MCQ array for that slide. The orchestrator will reclassify the slide as ignored (D-4.8).
4. **MCQ schema** (D-2.4, D-2.5, D-2.6) — Claude must emit ONLY this JSON (no markdown fence, no prose):
   ```json
   {
     "by_slide": [
       {
         "page_number": <int>,                    // matches the input
         "mcqs": [
           {
             "question": "<str>",
             "options": ["<str>", "<str>", "<str>", "<str>"],   // exactly 4
             "correct_indices": [<int>, ...],     // 1..4 entries; 0-indexed into `options`
             "rationales_per_option": ["<str>", "<str>", "<str>", "<str>"],   // exactly 4, one per option, in same order
             "source_page": <int>,                // = page_number of the slide this MCQ tests
             "language": "<str>"                  // ISO-639-1: 'en', 'de', etc.
           }
         ]
       }
     ]
   }
   ```
5. **Hard rules**:
   - `options` length is exactly 4.
   - `correct_indices` length is 1, 2, 3, or 4 (always a LIST, never a bare int — D-2.5).
   - `correct_indices` values are unique 0-based indices into `options`.
   - `rationales_per_option` length is exactly 4 (one per option, including correct ones — explain why each is right or wrong — D-2.6).
   - `source_page` equals the slide's `page_number` (no cross-slide questions in this phase).
   - `mcqs` is allowed to be `[]` for an ignorable/empty slide (D-4.8).
   - One entry in `by_slide` per input slide, in the same order as the input.
6. **Output discipline** — strict JSON only. No leading/trailing prose. No markdown code fence.
