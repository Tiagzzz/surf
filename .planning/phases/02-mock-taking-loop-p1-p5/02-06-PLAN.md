# Plan 02-06 — P5 Review Mock + Grading Formula

## Objective

Plan 06 ships P5 Review Mock: a top-pinned summary banner with the Swiss-formula final note + completion %, and a scrollable list of result Cards (one per question) with rationales upfront, difficulty score upfront, and a difficulty-breakdown expander for the 6 individual features. Centralizes the Swiss-formula grading into `app/brain/grading_formula/` so Plan 05 and Plan 06 share one implementation. Closes PAGE-05, MECH-03, and the review half of GRADE-04.

Purpose: P5 is the primary teaching surface — what makes Surf valuable to a student is *seeing why an answer was wrong* per D-4.2. Without this rationale view, the demo collapses into "score: 60%" with no learning value.

Output: `views/review_mock_exam.py`, three new pipelines (`question_render` for results, `summary_banner`, `grading_formula`), three sandboxes, full TDD coverage. Plan 05 will be SURGICALLY updated to delegate its grading to `app/brain/grading_formula` — this is a one-import change documented here.

### Interfaces this plan creates (Plan 07 + Phase 3 P6 dashboard consume)

- `app/brain/grading_formula/grading_formula.py`:
  - `swiss_note(correct: int, total: int) -> float` — `5.0 * correct / total + 1.0` rounded to 2 decimals; total==0 returns 1.0.
  - `pct_to_note(pct: float) -> float` — pct in [0..100] → note in [1..6].
  - `pct_for_next_note(current_pct: float, next_note: float, pass_threshold_pct: int) -> float` — informational delta to the next half-note step (used by summary banner). Note: `pass_threshold_pct` (per D-3.X in CONTEXT, slider in P7 Settings) is currently always 50 in Phase 2 (P7 Settings is Phase 3); `pct_for_next_note` keeps the parameter for forward-compat but treats it as informational only per MECH-03 wording.
- `app/mock_review/summary_banner/summary_banner.py` — `render_summary_banner(attempt_id: int) -> None` reads attempts row + computes via grading_formula.
- `app/mock_review/question_render/question_render.py` — `render_result_card(question: dict, answer_row: dict) -> None`.

### Plan 05 surgical change (consumed here)

`app/mock_take/answer_capture/answer_capture.py.grade_attempt` and `app/mock_take/attempt_save/attempt_save.py.complete_attempt` should delegate to `app.brain.grading_formula.swiss_note` for the note computation. This is a one-line `from app.brain.grading_formula.grading_formula import swiss_note` + replacing the inline formula. Plan 06 owns this edit; Plan 05's tests still pass because the formula is identical.
