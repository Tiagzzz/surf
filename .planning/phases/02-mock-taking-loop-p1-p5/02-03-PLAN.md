Purpose: PAGE-02 + closing PIPE-02 ("shipped 2026-04-30 — validate end-to-end in P2 flow"). Without P2, nothing else loads — every class id flows from here.

Output: `views/my_classes.py`, two new pipelines (`add_class`, `class_card_render`), `queries_classes` upgrade, three sandboxes (component x 2 + page), full TDD coverage.

- `app/my_classes/add_class/add_class.py` — `render_add_class_flow() -> None` runs a 4-state machine via `st.session_state['add_class_step']` ('upload' | 'cleaning' | 'review' | 'saving').

Schema (locked Phase 1):
- classes(id PK, user_id FK users.id, name, factsheet_json TEXT, pass_threshold_pct INT default 50, created_at).

Phase 1 reusable signatures (read-only — verify by reading the .py first):
